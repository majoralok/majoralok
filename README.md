## What I work on

- **Backend architecture:** modular Java and Spring Boot applications, API design,
  transactions, AOP, and rate-limiting strategies.
- **Applied AI:** RAG pipelines, typed model decisions, agent workflows, evaluation,
  observability, and human review.
- **System design:** small reference implementations that make distributed-system
  patterns easier to understand and test.

## Engineering principles

```text
Make behavior observable. Keep decisions inspectable. Put safety around side effects.
```

I prefer examples that run locally, document their trade-offs, and include a
deterministic path when external model access is unavailable.
